# baddies-studio-mic
A DIY portable studio microphone built using ESP32-C6, ICS-43434 MEMS microphone, SD card recording and custom electronics. It can record audio, save the recording as a WAV file and make the recordings accessible through a web interface.

# Why I Built This
I'm an electronics engineering student and also a creator on Instagram. As a new creator, buying professional equipment can be expensive, especially when you're just starting out.
So I thought:
"I'm an electronics engineer. Why should I buy it when I can build it?"
That's how Baddies Studio Mic started.
Instead of simply buying a studio microphone, I decided to build my own. This way, I could solve a real problem for myself while also learning how a microphone actually works—from capturing audio and processing it to storing recordings and building the electronics around it.
For me, this project is not just about making a microphone.
It's about the mindset of an engineer:
Don't just buy it. Understand it. Build it. Learn from it. Improve it.
And honestly, that's what makes this project special to me.
